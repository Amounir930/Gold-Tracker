# متتبع تداول الذهب | Gold Tracker Cockpit

تطبيق ويب خفيف وعالي الاستجابة، مصمم خصيصاً لمتداولي الذهب (XAUUSD) لمتابعة الأداء اليومي وإدارة رأس المال والأهداف والملاحظات النفسية، كبديل احترافي لجداول الإكسل مع إمكانية المزامنة المباشرة عبر GitHub بين الهاتف المحمول والكمبيوتر.

---

## الميزات الأساسية

1. **فصل رأس المال المزدوج**:
   - متابعة رأس المال الفعلي (Real Capital).
   - متابعة ميزانية التعليم والتجربة (Risk / Education Budget).
   - رصد القيمة الإجمالية للمحفظة فورياً.

2. **سجل التداول وفق أيام عمل البورصات العالمية**:
   - اعتماد 5 أيام عمل فقط في الأسبوع (من الاثنين إلى الجمعة).
   - استبعاد عطلة نهاية الأسبوع (السبت والأحد) تلقائياً.
   - اليوم الحالي معروض تلقائياً مع إمكانية اختيار وتعديل أي يوم سابق في أي وقت.

3. **الأهداف اليومية والمحاكاة التقديرية**:
   - **هدف يومي يدوي**: تحدده وتعدله بنفسك.
   - **هدف ديناميكي مقترح**: يُحسب تلقائياً **بناءً على الأداء الفعلي التراكمي فقط** (متوسط ناتج الأيام الرابحة دون التأثر بحجم رأس المال).
   - **محاكاة شهرية (21 يوم تداول)**: تقدير دقيق لمستوى المحفظة المتوقع إذا استمر متوسط الأداء اليومي على نفس الوتيرة.

4. **دفتر القواعد والتداول النفسي (CRUD Journal)**:
   - إضافة، تعديل، وحذف القواعد التداولية.
   - تصنيفات متخصصة: قواعد نفسية، استراتيجيات الدخول والخروج، إدارة المخاطر، والدروس المستفادة.

5. **المزامنة السحابية عبر GitHub (Cross-Device Sync)**:
   - يعمل محلياً في المتصفح تلقائياً (LocalStorage).
   - إمكانية الربط المباشر مع مستودع GitHub الخاص بك لحفظ وقراءة ملف `data.json` تلقائياً عبر GitHub REST API، مما يوفر مزامنة تامة ومجانية بين الهاتف والكمبيوتر.
   - أزرار تصدير واستيراد ملف JSON كنسخة احتياطية يدوية بنقرة واحدة.

## طريقة الرفع والتشغيل على GitHub Pages

1. قم بإنشاء مستودع جديد على حسابك في GitHub (مثلاً: `gold-tracker`).
2. ارفع ملفات المشروع (`index.html`, `README.md`, `robots.txt`, `sitemap.xml`, `llms.txt`, `humans.txt`).
3. توجه إلى إعدادات المستودع (Settings) -> ثم اختر (Pages).
4. في خيار **Build and deployment**:
   - Source: Deploy from a branch.
   - Branch: `main` / root (`/`).
   - اضغط Save.
5. سيعطيك GitHub رابطاً مباشراً يمكنك فتحه من متصفح الهاتف أو الكمبيوتر في أي وقت (مثال: `https://<username>.github.io/gold-tracker/`).

## إعداد المزامنة بين الهاتف والكمبيوتر

1. من حسابك على GitHub، توجه إلى:
   - Settings -> Developer Settings -> Personal access tokens -> Tokens (classic)
   - اضغط على **Generate new token (classic)**.
   - حدد خيار الصلاحية: `repo`.
   - انسخ التوكن (يبدأ بـ `ghp_`).
2. داخل التطبيق (سواء على الهاتف أو الكمبيوتر):
   - اضغط على زر **مزامنة جيت هاب** في أعلى الشاشة.
   - الصق التوكن واسم المستودع (مثال: `your-username/gold-tracker`).
   - اضغط **مزامنة وحفظ في GitHub**.
3. الآن، أي نتيجة تسجلها من الهاتف ستُحفظ في المستودع فوراً، وعند فتح التطبيق من الكمبيوتر ستظهر لك نفس البيانات دون الحاجة لأي خادم وسيط.
